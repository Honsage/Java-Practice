# Система управления библиотекой

Разработать консольное приложение для управления книгами в библиотеке.

## Требования

1. Добавление книги: Ввод названия, автора, года издания, ISBN (уникальный идентификатор).

2. Удаление книги: По ISBN.

3. Поиск книги: По названию (частичное совпадение, регистронезависимо) или по автору.

4. Выдача книги читателю: Книга должна иметь статус "Доступна" или "Выдана". Нельзя выдать уже выданную книгу. При выдаче фиксируем имя читателя и дату выдачи.

5. Возврат книги: Статус меняется на "Доступна", имя читателя и дата выдачи очищаются.

6. Просмотр всех книг: С выводом текущего статуса и читателя (если выдана).

7. Сохранение данных: При выходе из программы данные (список книг) должны сохраняться в файл (например, library.dat). При старте программы — загружаться из файла, если он существует.
