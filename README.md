# Java Practice

This repo contains labs and projects that are written in order to practice development with Java programming language. Projects can be used as code templates or study materials.

## Sections

### Java Core

_Study labs_ around java syntax, oop, exceptions, generics, collections (JCF).

### Concurrency

_Study labs_ around multithreading and asynchrony in java.

### NumericFilter

_Study lab_ to practice unit tests with JUnit.

### Restaurant Menu

_Study labs_ to practice different testing approaches: TDD, BDD, ATDD, SDD with JUnit, AssertJ, Cucumber. 

### RMI

_Study lab_ to practice remote method invocation in java.

### Maven Web App

_Study project_ to practice Spring Core, context and beans.

### Primitive Spring Authentication

_Study project_ to practice Spring Boot and Thymeleaf.

### LRU Cache

_Project_. Custom implementation of LRU Cache based on in-memory LinkedHashMap.

### Stack on Queue

_Project_. Algorithmic non-standard solution for task of implementation the stack by using queues. Solution based on sequential re-pushing. Each time new element added to 'stack', the queue is shifted on n-1 element, thus putting the new element to the head of the queue.
